# Table-1000 一期实施计划

## 三个研究方向

| 方向 | 研究内容 | 交付物 |
|---|---|---|
| **A. 仿真器与资产生成（底层）** | 从单张图片生成场景资产、sim–real 一致性；进一步研究仿真器特性、柔性物体与液体仿真 | 场景生成和编辑工具链、仿真环境与交互接口、sim-real 一致性实验报告 |
| **B. Benchmark 与评价（中层）** | 设计多个评估指标，VLM as Judge，VLM - Human 评估一致性 | 多个评估指标和实现，VLM 评估接口，VLM - Human 评估一致性报告 |
| **C. 算法接入与改进（上层）** | 接入 GPT 等大模型和 openpi、OpenDM 等 VLM baseline、评估其能力、失败诊断与算法改进 | 算法适配与运行代码、基线结果、改进方法及对照/消融实验 |

期望每个方向可以产出1篇可发表的成果，目标 IROS/RSS 2027。三个方向可以最终整理成一篇TRO。

## A 仿真器、场景资产生成

**研究内容**：
- 从单张图片生成场景资产：提供相应的工具链，包括资产生成的工具链，以及场景编辑器。
- 可交互场景：提供50个在仿真器中可交互的场景，并提供相应的 x1pro robot server 控制接口。每个场景需要提供随机初始化，以及10个有区分度的终止状态，每个场景需要足够复杂，有20-50个可交互的物体。
- sim-real 一致性：20个 ckpt 的 sim-real 对比实验，分析各个指标的一致性。
- （可选）仿真器特性：哪些仿真器具有更真实的物理模拟，哪些仿真器能够模拟柔性物体操作，流体操作，这些仿真器的计算速度如何。

**后续计划**：
- 2周：复现单图生成场景的demo，需要在一个仿真器中，从一张图生成一个可交互的场景，并且提供仿真器内x1pro的控制接口。提供至少3个场景，方便B的后续研究。
- 6周：提供20个场景，每个场景的随机初始化实现，以及每个场景5-10个终态。需要有足够的区分度。
- 12周：提供50个场景。并且完成 sim-real 的验证。

## B Benchmark 与评价

**研究内容**：
- 轨迹生成：根据指定的初始和终止状态，尝试生成出机器人的执行轨迹，可以将场景从初始状态移动到终止状态。
- 分层评估：设计多个评估指标，包括端到端的全流程评估，规划器评估（可以直接让 GPT-6 使用编辑器编辑场景），规划器下层接一个执行器，执行器评估（给定操作顺序执行），或者其他指标。
- VLM as Judege：研究使用大模型评估终态，提供 VLM 模型评估接口。VLM - Human 一致性实验，50个场景，每个场景 10 终止态，每次随机提供1个场景两个终态的图片，标注哪个收拾的更好。10个被试，每个被试标注200组结果。

**后续计划**
- 2周：熟悉仿真器，调研和尝试轨迹生成的方法，特别是高密度场景下如何自动生成轨迹。
- 6周：在 A 提供的 3 个场景上进行轨迹生成。VLM as Judge 的研究，准备人类评价实验。
- 12周：完成5000条轨迹生成。VLM - Human 一致性实验。


## C 算法接入与改进

**研究内容**：
- 模型接入：设计模型调用的统一接口，方便快速接入部署最新的模型，评估其性能指标。
- 模型评估：接入至少10个开源VLM模型或 闭源大模型 + Robot Harness 框架，评估这些模型的性能。
- （可选）算法改进：尝试在我们的benchmark上改进算法。

**后续计划**：
- 2周：先熟悉 RoboDojo 的 + openpi 的训练，RoboDojo + GPT-6 的接入
- 6周：在 A 提供的 3 个场景上尝试接入现有的方法，评估其性能。
- 12周：完成 table-50 的模型性能评估。

## RQ 与方向的关系

| RQ | 主责方向 | 协作方向与关系 |
|---|---|---|
| RQ1：模型规划能力差异与优化目标 | B + C | B 定义 benchmark 和指标，C 运行模型并分析改进方向 |
| RQ2：多解终态评价 | B | B 组织人评与大模型 judge；|
| RQ3：分层失败诊断 | C | B 提供分层指标、轨迹与标签，A 提供仿真干预接口 |
| RQ4：仿真是否预测真机 | A | B 提供测试场景与标准，C 提供策略，A 执行两域配对实验 |
| RQ5（附加）：仿真数据价值 | C | B 提供仿真轨迹、数据划分和评价协议，A 提供环境与真机支持 |
| RQ6（附加）：仿真器差异 | A | B/C 提供统一场景、评价标准与策略 |
