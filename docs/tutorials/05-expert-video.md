# 05 渲染专家轨迹视频

在第四章的单次运行上加 `--video`，同一次仿真同时录制三个视角：

```bash
"$ISAAC_PYTHON" scripts/tasks/drawer_pen.py --offsets 0 0 0 0 --output outputs/drawer-pen/center-video --gpu 0 --video
```

| 视频 | 视角 |
| --- | --- |
| `wide.mp4` | 远景，从桌子右前方看机器人、桌面和两件物体 |
| `close.mp4` | 抓持近景，对准抽屉开口、把手与笔区 |
| `head.mp4` | 机载相机，挂在头部彩色相机光学坐标系上，随头部运动 |

三个视角分辨率均为 960 × 540，每 10 个物理步（0.04 s 仿真时间）渲染一帧，视频按 25 fps 播放，即 1 倍速；每帧左上角标注仿真时间和当前阶段。渲染在两个物理步之间同步进行，不推进物理时间；有无 `--video` 走同一条物理轨迹，计时分别记在 `timings.step_s` 与 `timings.render_s`。

视角定义在 [run.py](../../table_1000/tasks/run.py) 的 `VIEWS` 和 `views()` 中。固定视角给相机位置和注视点；机载视角给父 prim 和 USD 相机约定下的局部位姿（−Z 朝前、+Y 朝上），由 URDF 中光学坐标系（+Z 朝前、+Y 朝下）换算得到。

[cameras.py](../../table_1000/runtime/cameras.py) 只用一个相机和一个渲染产品，逐个视角移动相机再渲染。实测每个视角各用一个渲染产品时，annotator 会返回其他视角的画面。每次移动相机后多渲染一帧再取图。三个视角时渲染耗时约为物理步进的 4–5 倍。

验收时先看远景，确认整个流程：抽屉拉开、笔被抓起并留在抽屉里、手撤出、抽屉合上。再看近景，检查手指与把手、笔的接触，以及手和手臂是否穿过桌子或盒体。结果以 `result.json` 与 `contacts.json` 为准，画面用来核对接触记录。
