# 按压解锁短壳美工刀

## 2026-10-22 总控独立验收

独立审查完成，accepted_with_conditions：CPU1/GPU4十项、原生四环境补充轨迹、生命周期及三轮性能证据通过。保留步长/求解器、GPU1.417mm落放穿透、工程估计及非严格参考环境等边界；不重复测量。


![preview](three_quarter.jpg)

白色圆端短壳、浅绿色按压滑钮和深色滑槽，收刀包络约95×20×10 mm；尺寸与机构参数均为工程估计。刀口在−X端，原点为底面中心，+X向后、+Y为宽度、+Z向上。

按住滑钮，使锁舌下降退出壳内档槽，再沿刀身前推或后拉刀片。到档位松手后，滑钮由弹簧驱动向上回弹，锁舌入槽重新锁止。刀片只沿轴向移动，不随按压上下浮动。档间松手可能尚未锁住，需继续轻推/拉至邻近槽位；没有强制吸到档位或自动收刀。

## 结构与能力

三个刚体、两个原生滑动关节，保存初态为刀片收回、按钮弹起。实际资产树（省略视觉/碰撞网格）：

- utility_knife.slide：刀壳→载片架，正方向−X，0–20 mm，档位0/5/10/15/20 mm。收回时刀尖距出口10 mm，全伸时露出约10 mm。
- utility_knife.press：载片架→滑钮，正方向−Z，0–1.5 mm。有效按足量约1.2 mm，实际解锁取决于锁舌是否离槽。
- 刀壳、内部通道和出口具有对应碰撞净空；刀片厚0.3 mm，未把薄刀片加厚成代理。锁止由锁舌与齿条的真实接触产生，两者的碰撞保持开启。
- 只表达按压解锁、受力推拉、回弹及有限载荷锁止；不模拟切割、断刃、弹簧钢应力或任意冲击下的安全锁定。

## 物理参数

physics.py为权威配置，无行为脚本，加载生成目录中的object.usdz。

| 参数 | 值与依据 |
| --- | --- |

| 质心/惯量 | PhysX按各刚体碰撞形状估算，未按真实壳壁/钢片密度标定 |

源模型的BOX由物理层按其精确包围尺寸表达为原生USD Cube，几何弱层不修改、不加厚；本机网格boundingCube表示在亚毫米锁舌处出现卡滞，原生Cube对照已能按压/回弹。形状等价须在重开检查中核对。槽宽1.1 mm、锁舌轴向厚0.7 mm，锁止存在有限间隙和求解误差，不代表刚性无限承载。

## 实验

physics_test.py使用外力作用于滑钮或刀壳；固定刀壳属于实验夹具。初始化后不写动态位姿，不修改锁止状态、关节限位或碰撞过滤来演示功能。记录的力是施加外力，不冒充接触反力。

| 实验 | 内容 |
| --- | --- |
| lock_pressure | 未按/浅按/按足三实例相同0.5 N轴向载荷对照 |
| cycle | 五次按压—推出—松手—按压—收回—重锁，检查刀片相对高度 |
| loaded_unlock | 保持正/反0.5 N轴向载荷时按压解锁 |
| relock_between | 档间松手后等待，再轻推至槽位；不瞬移对槽 |
| relock_slots | 五档从按足状态松手回弹，再受正/反0.5 N保持力 |
| hold_gravity | 五档、刀口朝上/下十实例保持对照 |
| free_reaction | 无重力自由整体在滑钮外力下运动，检查总线动量及闲置实例独立性 |
| drop_states | 收回/伸出/侧放的30 mm低落放，检查穿地、限位与稳定 |
| push_release | 收回/伸出刀壳受力推移，撤力后停止 |
| side_tip | 侧放高位侧推与闲置对照 |

低落放等有地面实验采用理想地面摩擦0.40/0.30、contactOffset **1.5 mm**，大于内部接触裕量，以在4 ms下提前建立高速接触；不据此预测准确首次接触时间或冲击峰值。锁止漂移设计判据≤0.5 mm、按足解锁后移动≥5 mm；0.5 N是受测保持载荷，不是失效强度测量。

## 历史CPU验证与数值边界

以下为旧框架CPU历史结果，不代表新版CPU/GPU已经验收。

本版本十项正式实验完成完整视频及曲线审查，另有4/2 ms数值对照、USD重开与独立目录加载、停止/复位、卸载和多实例检查。五次全伸缩循环端点最大误差约0.0026/0.0012 mm，刀片相对高度变化约0.0065/0.0025 mm（4/2 ms）。五档回弹后正反0.5 N加载时最大档位偏差约0.474/0.257 mm；含机械间隙、瞬态求解误差，不承诺精确零位。

按压起始、回弹和反向加载有短暂弹簧/接触振荡；不能据此解释实际手感或冲击强度。保持±0.5 N轴向载荷时，1.2 N按压力可解锁；1.0 N用于普通按足动作，0.28 N用于浅按对照，均未实测标定。浅按在4 ms端点试验几乎无位移、2 ms最大约0.372 mm，微载按压形变有明显步长敏感性；仅对受测锁/解锁状态与保持判据作验收。解锁后重力能否单独推动载片架还受约0.05 N静导向阻力影响；移动总成4 g的重力约0.039 N，不保证按足时竖直自滑，受测竖直朝向仍有约0.05–0.11 mm缓慢数值漂移，不能称绝对静止。30 mm低落放仅验证受测朝向，地面1.5 mm接触裕量不能外推任意冲击安全或精确冲击峰值。

加载修订与失败边界：

- free_reaction由0.8延至1.2 s，满足独立benchmark完整实验预热至少1 s；延长后发现受力件会撞上闲置对照，把闲置Y从0.04移至0.12 m并扩大相机。外力与2%动量判据不变。
- hold_gravity原0.1 s突变加载在GPU出现0.530–0.557 mm瞬态偏差。当前保留±0.5 N峰值、各0.3 s平台及3.6 s总时长，过渡改0.3 s；最大偏差仍按全时段原0.5 mm验收。本结论只覆盖当前缓加载，原突变条件未通过GPU。
