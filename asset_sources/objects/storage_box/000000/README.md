# 大号透明圆筒盒

![preview](three_quarter.jpg)

无色全透明塑料圆筒，仅白纸标签及蓝边不透明，无盖，外径150 mm、盒身高90 mm。底板和侧壁为一个完整刚体，无关节；底面中心为原点，+Z 向上。

```text
storage_box.container [rigid]
  floor
  label_border
  mouth_rim
  paper_label
  walls
```

## 物理配置与能力边界

通过统一构建入口生成 `object.usdz`；无行为脚本。质量为盒体112.862 g，按现有24边形底板/侧壁壳体体积与透明硬聚合物候选密度1180 kg/m³估算，忽略标签质量，未经实物测量。质心与惯量由空心碰撞几何估算。静/动摩擦0.65/0.50，恢复系数0，接触/静止裕量0.1/0 mm；CPU TGS、16/4迭代、CCD及推测CCD，线/角阻尼0。

底板与24段凸侧壁保留内腔。口沿装饰、纸带及蓝边没有独立碰撞，口部接触由原侧壁上缘表示；不模拟薄壁变形、破裂或真实冲击载荷。

`physics_test.py` 登记正放/侧放20 mm落放、高低位推移与倾倒、4 mm/5 g球的底部/四向内壁及上缘接触、零重力质心/偏心/空闲实例冲量。高低位对照采用0→1.2mg的1s线性斜坡、峰值后4ms撤力，地面采用静/动摩擦1.25/0.80的粗糙理想地面夹具；该地面不属于资产。球探针为实验夹具，其接触裕量2 mm、速度目标35 mm/s、水平力上限4 mN，记录实际施力，不冒充接触反力。

接受条件：末0.5 s盒体速度小于10 mm/s、漂移小于1 mm；正放/侧放终态误差小于5°；低推滑移超过5 mm且倾角小于10°，高推倾角超过45°；球探针到达底及目标壁，几何穿透小于1 mm，盒口支撑高度误差小于1 mm；落放最大几何穿地小于2 mm；自由冲量线动量误差小于1%、偏心引起旋转、空闲实例无串扰。

当前状态：四项正式受力实验、完整309帧/四张曲线组内审查、两类RTF与实例/停止复位/独立目录加载已通过，待总控及PR复核。真实多件装填、跨款配盖及机器人整理属于后续组合验证。

步长对照：2 ms下落放瞬时穿地约0.719 mm（4 ms约1.347 mm）；推倒后终态不同，4 ms回正静止而2 ms侧卧缓慢滚动，后者4 s末仍约53 mm/s，未通过同一末段稳定检查。不能用本代理预测准确翻倒终态或真实滚动阻力。
