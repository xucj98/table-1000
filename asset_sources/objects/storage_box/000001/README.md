# 中号透明圆筒盒及放置盖

![preview](three_quarter.jpg)

无色全透明盒体及浅盖，仅白纸标签和蓝边不透明，盒身外径90 mm、高50 mm；浅盖外径94.4 mm，装配总高52.25 mm。盒体和盖为两个独立完整刚体，无永久关节或卡扣；盖沿可竖直取下、翻转放置后再盖回。盒体原点为底面中心，盖原点在盖板内面中心，+Z 向上。

## 物理配置与能力边界

通过统一构建入口生成 `object.usdz`；无行为脚本。质量为盒体38.077 g、盖19.449 g，按现有24边形底板/侧壁壳体体积与透明硬聚合物候选密度1180 kg/m³估算，忽略标签质量，未经实物测量。质心与惯量由空心碰撞几何估算。静/动摩擦0.65/0.50，恢复系数0，接触/静止裕量0.1/0 mm；CPU TGS、16/4迭代、CCD及推测CCD，线/角阻尼0。

底板与24段凸侧壁保留内腔。口沿装饰、纸带及蓝边没有独立碰撞，口部接触由原侧壁上缘表示；不模拟薄壁变形、破裂或真实冲击载荷。盖板与围裙属于独立刚体，仅通过原生接触落座，无卡扣、永久关节或吸附，不承诺倒置保持或偏盖自动居中。

`physics_test.py` 登记正放/侧放20 mm落放、高低位推移与倾倒、4 mm/5 g球的底部/四向内壁及上缘接触、零重力质心/偏心/空闲实例冲量。另登记正盖/12 mm偏盖自然落座、两次竖直受力揭盖后撤力、60°支撑与120°/180°固定盒姿态下盖的自由滑落。高低位对照采用0→1.2mg的1s线性斜坡、峰值后4ms撤力，地面采用静/动摩擦1.65/1.40的粗糙理想地面夹具；该地面不属于资产。球探针为实验夹具，其接触裕量2 mm、速度目标35 mm/s、水平力上限4 mN，记录实际施力，不冒充接触反力。

接受条件：末0.5 s盒体速度小于10 mm/s、漂移小于1 mm；正放/侧放终态误差小于5°；低推滑移超过5 mm且倾角小于10°，高推倾角超过45°；球探针到达底及目标壁，几何穿透小于1 mm，盒口支撑高度误差小于1 mm；落放最大几何穿地小于2 mm；自由冲量线动量误差小于1%、偏心引起旋转、空闲实例无串扰。正盖板相对盒口高度误差及径向偏差小于1 mm，末速小于10 mm/s；两轮揭起均分离超过10 mm后回座；倾斜与倒置盖离座位移超过10 mm。

当前状态：七项正式受力实验、全部562帧/七张曲线组内审查、两类RTF与实例/停止复位/独立目录加载已通过，待总控及PR复核。真实多件装填、跨款配盖及机器人整理属于后续组合验证。

倾斜滑落实验使用2 ms物理步（其余4 ms），薄盖撞地最大瞬时穿透诊断约1.141 mm；同项4 ms约4.187 mm未通过2 mm上限，保留为步长敏感性限制。偏盖落座每4 ms几何SAT诊断峰值约0.808 mm，不能把40 ms稀采样峰值当完整误差。
