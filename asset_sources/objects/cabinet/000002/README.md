# 洞洞板双抽屉收纳架

![四分之三视图：左视觉，右碰撞](three_quarter.jpg)

白色洞洞板与右侧三层斜格柜、下方平台和抽屉外壳组成一个主体，配透明收纳盒、白色挂钩及两个烟灰透明抽屉。主体约 **320 × 220 × 380 mm**；闭合装配含把手、安装销约 **320 × 233 × 380 mm**。尺寸为工程估计，非实测。

共五个完整刚体组件：`housing`、`tray`、`hook`、`drawer_left`、`drawer_right`。左右抽屉各通过一个 `SLIDER` 连接主体，行程 **0–170 mm**，正值沿 **−Y** 拉出。收纳盒和钩子以独立直插销组件装配到洞洞板，沿 −Y 拔出；背面安装结构为推定结构。每个抽屉的盒底、四壁、前板和把手属于同一刚体。

原点为主体底面中心，+X 为宽度，+Y 向后，+Z 向上。
