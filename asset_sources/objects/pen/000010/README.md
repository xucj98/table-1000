# 白色细带盖笔

![preview](three_quarter.jpg)

白色细笔杆与白色带笔夹空心帽，闭合150×11×12mm。

笔身 `body`、空心笔帽 `cap` 和3个内部球形卡扣从动件，共5个刚体。笔身与笔帽可完全分离；每个从动件以原生径向 SLIDER 连到笔帽。−X朝笔尖及拔帽方向。

## 资产树

从当前 `object.blend` 实际父子关系导出，省略视觉/碰撞网格。部件随所属刚体运动。

```text
body [rigid]
  detent_ridge
  barrel
  neck
  rear_plug
  steel_point
  tip
cap [rigid]
  clip
  end
  lip
  shell
cap_ball1..3 [rigid]
  ball
```

## 第二章物理能力

内部卡扣采用原生球形接触、颈部环形凸棱、有限径向行程和弹簧 Drive。保持、脱开与再次盖合均由接触求解，不需要行为脚本或测试夹具维持连接。保留外形与空腔，仅扩大隐藏帽口内部净空并添加内部机构。帽沿−X拔出；从动件沿各自关节局部+Y向外（关节框架绕笔纵向X旋转，世界径向不变），限位[0, 0.00035]m。

|参数|工程取值|
|---|---:|
|笔身 / 帽壳质量|7 / 2 g|
|从动件数量 / 半径|3 / 0.35 mm|
|每个从动件有效质量|0.0837402 g|
|径向弹簧刚度 / 阻尼|765.625 N/m / 0.13125 N·s/m|
|向内驱动目标（预压）|−0.13125 mm|
|凸棱或斜坡高度|0.196875 mm|

从动件质量是约同尺寸实钢球60倍的有效惯量代理，按半径立方缩放；不是实钢密度。质量、弹簧和摩擦均未实物标定，质心/惯量由碰撞体积估算。塑料静/动摩擦0.35/0.30，球为金属接触0.20/0.15；平均组合、零恢复，contact offset 0.1mm/rest offset 0；无额外刚体线性/角阻尼。小接触采用1ms、TGS位置/速度迭代32/8、每体CCD开，稳定阈值0、最大去穿透速度1m/s；应单列于4ms、16/4标准条件之外。加载本新盖时应将仿真世界物理步长设为1ms；导入USDZ本身不会修改世界步长，不能把4ms视为已验收的等价条件。

凸体在USD中将局部顶点放大100倍并以原生形状缩放0.01补偿，世界尺寸不变，避免PhysX固定烘焙容差删除亚毫米凸棱。该设置随资产分发，不依赖全局烘焙参数；Blender仍为米单位原网格。

`physics_test.py` 提供六项独立实验：`pull_comparison`（紧/松渐拉、完全分离后接住放稳）、`close`（轻推停位、加力座合、撤去帽夹具）、`gravity_rotation`（只夹笔身翻转）、`cycles`（连续三次拔插，无状态复位）、`free_reaction`（自由帽受力、笔身反作用及闲置实例）、`low_drop`（最低点20mm落放与稳定）。当前CPU1/GPU4六项功能复验和完整视频/曲线组内审核通过；当前输入的正式性能仍待统一队列测量，历史候选性能仅供追溯。

当前渐拉协议下紧/松帽完全分离末次外力CPU约0.5223/0.025N、GPU各环境最大约0.6713/0.025N；0.08N弱拉保持。轻推0.04N停在凸棱前，座合末次施力CPU约0.4600N、GPU约0.4346N，撤去帽载荷和夹具后开口CPU约0.04136mm、GPU约0.04757mm。动态末次施力不是准静态实测拔力或接触反力。拉拔导向期间轴向刚度/阻尼为0，完全分离后才接住；盖合导向轴向阻尼10N·s/m，座合后释放。

能力限于正确朝向、低速引导装配、紧松保持差异和宏观低落。不能预测真实塑料变形、精确冲击载荷或真实脱帽高度；错向不自动吸正，跨ID换帽与机器人整理任务另行验收。正式RTF采用实际RTX RT2采样设置，非严格1spp；视频Actions栏只列计划动作，自定义加载回调以applied_force_x和曲线为准。

按[第二章教程](../../../../docs/tutorials/02-physics-assets.md)显式选择本ID构建，加载产物目录的 `object.usdz`。`object.py` / `physics.py` / `physics_test.py` 分别保留逐款几何、质量和实验协议参数，共享实现来自同版本 `table_1000.modeling.pen_detents`、`table_1000.physics.pen_assets`、`table_1000.physics.pen_tests`；源码快照重建依赖同版本包。身份字段不扩展。

### 2026-10-23 原生关节坐标修复与复验

原GPU自由反作用中，闲置帽球四环境末速1.585–1.691e-5m/s超过1e-5门槛。原生6D速度记录证实帽组件从零缓慢积累转动；只取消预载的控制可消除残速，但改变机构，未采用。最终保留预载及原生滑动机构，仅将三关节自由坐标从局部X换为局部Y，两个端点框架改为绕笔纵向X的纯旋转。世界滑动仍为原径向，笔纵向精确位于锁定轴。float32表示下最大轴向量差1.22e-7，对0.35mm行程端点差约4.28e-11m；USD逐属性审核仅改变三关节axis/localRot0/localRot1共9字段，几何文件完全复用。质量、惯量、摩擦、锚点、Drive、预载、限位、载荷、UUID及全部判据均保持。

修复后CPU1和GPU4各六项全部重新执行并通过原断言，十二项全片与曲线组内审核通过。由于资产原生关节路径改变，CPU六项全部复测，未复用旧通过。GPU自由反作用四环境闲置全部刚体最大末速为[4.5560, 6.3983, 6.3983, 6.3983]e-6m/s；原1e-5门槛保持。独立GPU1/GPU3诊断轨迹一致，正式生产入口复验再次通过。尚无maximal-coordinate D6冲量接口证据，未声称定位PhysX内部实现根因；结果仅覆盖声明条件。

所有测试1ms（偏离标准4ms）。CPU1使用TGS、scene最小位置/速度迭代1/0、scene CCD开；GPU4使用scene最小64/16，free_reaction按已批准例外使用PGS且关闭每迭代重复外力，low_drop沿用PGS，其余TGS，GPU scene CCD关。资产rigid迭代32/8、CCD字段开不能冒充GPU场景CCD开。拔盖保持既有约15°稳定支撑面、1.2s下降段、原释放时刻、2.4s稳定段及0.5s尾窗。运行时仅张量施力/原生夹具目标，无资产瞬移或USD物理属性写入。

新录像逐帧解码后全序列审阅，GPU画面显示env0，数值验证覆盖四环境全部刚体。白笔在浅色背景对比有限，翻转分离另查原尺寸画面；精密缝隙由曲线判定。低落允许瞬态约毫米穿地，须稳定恢复，不能用于精确冲击预测。执行完成、组内功能审核与总控验收分开；总控独立验收待完成。当前输入正式性能已具备入队条件，尚不将普通功能RTF作为正式无渲染RTF。
