# 蓝色钢珠卡扣粗笔

![preview](three_quarter.jpg)

蓝色连续笔杆带浅色标签和半透明笔帽，约 179 × 20 × 20 mm。笔身、帽壳和三颗内部钢球，共 **5 个物理刚体**。帽沿 −X 拔出；三球通过径向滑动关节连接帽壳，行程 0–0.8 mm。球仅在碰撞预览显示。

原生钢珠弹簧卡扣；参数为未标定工程代理。

```text
body [rigid]
  barrel
  detent_ridge
  label
  neck
  tip
cap [rigid]
  end
  lip
  shell
cap_ball1..3 [rigid]
  ball
```

## 物理实测

Isaac Sim 5.1.0 / Isaac Lab 2.3.2，4 ms 步长；CPU 后端 1 个环境，GPU 后端 4 个并行环境。未标定的仿真值。

| 物理量 | CPU | GPU | 测试与测量方式 |
| --- | --- | --- | --- |
| 拔帽力（紧帽） | 2.36 N | 2.73 N | `pull_comparison`：夹持笔帽以 5 mm/s 沿 −X 拉出，取拉力峰值 |
| 拔帽力（松帽，初始开口 3 mm） | 0.007 N | ≈ 0 N | 同上 |
| 合帽力 | 3.74 N | 2.14 N | `close`：夹持笔帽只沿笔轴推（横向由笔杆导向，姿态保持），0.3 N 限力推到卡扣前停住，然后以 0.6 N/s 提高上限，取盖紧（开口 < 0.2 mm）前的最大推力 |
| 重力翻转 180°（30°/s）后的状态 | 紧帽保持，松帽滑落 | 紧帽保持，松帽滑落 | `gravity_rotation` |

CPU 与 GPU 的合帽力相差约 1.7 倍，见 [#15](https://github.com/xucj98/table-1000/issues/15)。GPU 合帽力在 1 个环境时为 2.13 N：合帽过程对求解顺序敏感，环境数改变后结果略有不同。

性能（4 项测试的范围；RTF 按单个环境计）：

| 后端 | 无渲染 RTF | 含视频 RTF | 本进程 CPU 占用 | GPU 利用率（无渲染 / 含视频） |
| --- | --- | --- | --- | --- |
| CPU，1 个环境 | 0.33–0.57 | 0.24–0.34 | 2.0–2.5 核 | 6% / 5–8% |
| GPU，4 个环境 | 0.11–0.20（合计 0.45–0.80） | 0.10–0.16（合计 0.39–0.62） | 1.3–1.4 核 | 36–61% / 32–55% |

测量机器为 AMD EPYC 7542（128 线程）加 RTX 4090，与其他任务共享：1 分钟负载 7–17，每张显卡上共有 4 个计算进程（含本进程）。GPU 利用率是整卡数据，包含这些进程。“合计”为所有环境的仿真秒数之和除以墙钟时间。
