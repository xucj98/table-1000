# 暖白镂空文件篮

![preview](three_quarter.jpg)

暖白 PP 外观，外形约328×242×100.5 mm（工程估计）。两端提手穿孔、连续圆角篮沿及顶部内腔保留；底面中心为原点，+X长边、+Y短边、+Z向上。一个完整刚体，无关节。小椭圆孔仅视觉镂空，碰撞采用实壁近似，不支持细物穿孔。

```text
file_basket
  shell [rigid]
    end_wall1..2
    floor
    long_wall1..2
    rim
    rounded_corners
```

## 物理属性与实验

`physics.py` 配置单一 0.280 kg 刚体，PP 静/动摩擦 0.40/0.30、恢复系数 0；这些是工程估计，尚未经称重或材料标定。质量估计参考 3 mm 实心底板约 164 g 及开孔壁/加厚沿约 100–130 g。质心与惯量由碰撞几何估算，小孔填实会造成质量分布误差。不模拟 PP 弯曲、提手变形或破坏。

构建后直接加载 `object.usdz`，无需行为脚本；依赖同版本 `table_1000` 包。`physics_test.py` 提供底放/侧放渐增推力与撤力、50 mm 落放、双端/单端提手孔接触提拉，以及零重力质心/偏心冲量对照。提拉仅用实验内夹持控制接触杆经接触传力，无固定篮体约束，不改写运动中篮体位姿；记录外力不代表接触或夹具反力。默认 CPU PhysX/TGS、4 ms、16/4 迭代、CCD 与 speculative CCD、0.1 mm 接触裕量。

上述实验不涵盖装书承载、细物穿过小椭圆孔、机器人抓取或真实材料冲击预测。新版执行状态及指标由 physics_test/summary.json 汇总；完整视频与曲线仍须实际审查。

## 复现与限制

在仓库根目录使用已配置的仿真Python运行：

    python scripts/assets/physics_test.py --assets file_basket/000000 --physics isaac-cpu isaac-gpu --gpus 0 --scripts asset_sources/objects

--gpus应使用总控分配的卡；功能验证通过后再添加 --benchmark。构建及结果目录由单一写入方维护。加载入口为 object.usdz，physics.py与几何未改变；新报告不借用历史通过结论。小椭圆孔仍为实壁碰撞，不支持细物穿孔；未验证装书、机器人抓取、PP柔性或破坏，GUI交互未测。完整本款新版交付仍等待提杆公共报告修复、提拉正式性能及GPU落放/自由冲量中断后的标准性能补测。
