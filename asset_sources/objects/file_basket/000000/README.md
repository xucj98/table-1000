# 暖白镂空文件篮

![preview](three_quarter.jpg)

暖白 PP 外观，外形约328×242×100.5 mm（工程估计）。两端提手穿孔、连续圆角篮沿及顶部内腔保留；底面中心为原点，+X长边、+Y短边、+Z向上。一个完整刚体，无关节。小椭圆孔仅视觉镂空，碰撞采用实壁近似，不支持细物穿孔。

```text
file_basket
  shell [rigid]
    end_wall1..2
    floor
    long_wall1..2
    rim
    rounded_corners
```

## 物理属性与实验

`physics.py` 配置单一 0.280 kg 刚体，PP 静/动摩擦 0.40/0.30、恢复系数 0；这些是工程估计，尚未经称重或材料标定。质量估计参考 3 mm 实心底板约 164 g 及开孔壁/加厚沿约 100–130 g。质心与惯量由碰撞几何估算，小孔填实会造成质量分布误差。不模拟 PP 弯曲、提手变形或破坏。

构建后直接加载 `object.usdz`，无需行为脚本；依赖同版本 `table_1000` 包。`physics_test.py` 提供底放/侧放渐增推力与撤力、50 mm 落放、双端/单端提手孔接触提拉，以及零重力质心/偏心冲量对照。提拉仅用实验内运动学杆经接触传力，无固定篮体约束，不改写运动中篮体位姿；记录外力不代表接触或夹具反力。默认 CPU PhysX/TGS、4 ms、16/4 迭代、CCD 与 speculative CCD、0.1 mm 接触裕量。

上述实验不涵盖装书承载、细物穿过小椭圆孔、机器人抓取或真实材料冲击预测。执行完成与视频/曲线验收分开记录在生成实验的 `result.json`。
