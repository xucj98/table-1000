# 半透明胶带卷

![preview](three_quarter.jpg)

乳白胶带卷和纸芯，约 61 × 61 × 20 mm，中孔内径约 32 mm。

整体为一个刚体，2个语义部件、32个凸碰撞扇区，无关节。

第二章物理采用完整胶带卷的工程近似：质量 0.050 kg；绕带接触材料静/动摩擦
0.38/0.28，纸芯为 0.45/0.32，恢复系数为 0。质量分布、摩擦和接触裕量尚未实物标定，
质量按绕带约39.7 cm³×1.2 g/cm³与纸芯约3.18 cm³×0.7 g/cm³估计并取整；
质心与惯量由均匀碰撞体积估计。圆周为16边形，立放初态宜使一个平面着地；
滚动衰减含多边形接触损失，并非已标定的滚动阻力。当前诊断中同载荷的
4 ms/2 ms滚动行程为166.6/226.4 mm（相差35.8%），仅支持固定步长下的定性整理运动，
不用于实物停止距离预测。`physics.py` 提供 USD 物理层，`physics_test.py` 覆盖滚动衰减、
侧向倾倒、内孔理想圆柱接触和两种姿态落放及自由冲量。能力边界是整体卷：不模拟放卷、撕胶、粘附或
胶带端头互锁。无行为脚本，构建后的加载入口为 `object.usdz`。
新版CPU/GPU验证与性能状态见下方；历史诊断不计作新版验收。

## 物理测试

在仓库根目录构建物理资产后运行：

    uv run python scripts/assets/physics_test.py --assets tape/000000 --physics isaac-cpu isaac-gpu --gpus 0 --scripts asset_sources/objects

功能及媒体检查通过后，按项目统一测量队列提交对应后端与测试项；媒体未通过的测试不入队。
结果入口为构建目录的 physics_test/summary.json，两后端分别在 isaac-cpu/、isaac-gpu/。
内孔夹具在环境内初始化前声明，通过PhysX张量运动；GPU四环境逐一验证穿孔、侧推、稳定性与穿地阈值。
不在运行中修改USD位姿或物理结构；不夹持或写入动态卷体位姿。
