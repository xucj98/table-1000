# 红纸套橡皮

![preview](three_quarter.jpg)

白色细长橡皮、红色纸套及简化印花/条码，约 60 × 15 × 10 mm（工程估计）。

橡皮、纸套与印花合为一个搬运刚体，无关节。原点为底面中心，+X 为长度、+Y 为宽度、+Z 向上；纸套不可单独滑脱。

从实际模型导出的资产树（省略视觉/碰撞网格）：

```text
eraser
  body [rigid]
    paper_sleeve
    rubber
    sleeve_print
```

三个部件分别表示固定纸套、橡皮本体及纸套印花；均随整件运动，无独立刚体或关节。

## 物理资产与实验

`physics.py` 提供 `author(geometry_path, output_path)`，通过统一物理构建入口生成
`object.usdz`，可直接加载；没有行为脚本。一个刚体的质量为 0.014 kg：约
8.41 cm³ 橡胶按 1.60 g/cm³，加约 0.484 cm³ 纸套按 0.9 g/cm³，取整至
14 g。质心与惯量由引擎按碰撞形状估算，未按纸/胶密度分别标定。

橡胶静/动摩擦为 0.85/0.70，纸套及印花为 0.45/0.35，恢复系数为 0，
摩擦使用 average 组合。碰撞 contact offset 为 0.05 mm，rest offset 为 0；
刚体无额外线性/角阻尼，16/4 求解迭代，开启 CCD 与 speculative CCD 处理转动接触。以上均为未实测的工程估计。
印花只有视觉网格，不产生独立接触；四个纸套碰撞和一个橡胶碰撞分别继承对应材料。
纸套仅厚 0.2 mm，接触裕量与数值误差可能导致混合纸/胶接触，不能把整件的
起滑载荷当作单一材料摩擦实测。

`physics_test.py` 使用统一 `TESTS/TestContext`，登记七项实验：

| 名称 | 内容 |
| --- | --- |
| `contact_slide` | 平放纸套与端立露胶的渐增质心推力、撤力和停止距离；露胶实例使用实验专用的原生转动导向，三向平移自由，另有未加载端立对照 |
| `free_tip` | 端立露胶、无导向，两实例比较高点推力/撤力与静置，观察自由翻倒 |
| `drop_orientations` | 纸套底/顶、露胶端三朝向，从最低碰撞点高 50 mm 自由落放 |
| `free_impulse` | 零重力下质心/偏心等冲量及闲置实例对照，核对线动量与转动 |
| `guide_release` | 零重力转动导向，在持续力矩下张量释放，核对状态连续性与独立闲置实例 |
| `stop_reset` | 运动/旋转中的整体停止、复位与继续积分，逐环境核对恢复状态及后代相对变换 |
| unload_reload | 同一stage/session内停止后真实移除全部环境副本，两轮重载；保留实例继续自由运动，不以新context代替 |

导向夹具只用于实验，不随资产分发，也不代表资产可以自由端立滑动。新版导向在
首次仿真前以 `ctx.grip` 声明，`axes(linear=(0, 0, 0), angular=True)` 仅保持转动，
三向平移不施加控制；实验结束通过张量释放，不在运行中增删 USD 关节或写动态位姿。
它使用有限增益，不能与旧版理想锁转导向视为完全相同。力列区分施加推力与夹持力，
接触反力未采样；GPU 夹持力矩由驱动估算，本轮 guide_release 在已知非零力矩下
该记录列全为零，不能当作实测反力或证明导向不施力。释放连续性与运动结果由状态张量核对。
每个并行环境均独立检查原验收条件，
`trace.csv` 中 `env0`–`env3` 列和 `experiment.per_environment` 留存各环境证据。

### 复现与能力边界

在仓库根目录使用环境维护方已配置的解释器。通用功能入口如下；本项目共享机器上的
功能复测须遵循本地资源政策，通过共享启动器自动领取 GPU/CPU，无需另询卡号或预算：

```bash
python scripts/assets/physics_test.py --assets eraser/000000 --physics isaac-cpu isaac-gpu --gpus <allocated_gpu> --scripts asset_sources/objects
```

功能及媒体通过后，按原四项可比范围测量。共享主机先查统一队列，同输入任务不重复提交；项目内由资源入口冻结输入后自动执行以下通用 CLI：

```bash
python scripts/assets/physics_test.py --assets eraser/000000 --physics isaac-cpu isaac-gpu --gpus <allocated_gpu> --scripts asset_sources/objects --tests contact_slide free_tip drop_orientations free_impulse --benchmark
```

新增生命周期检查独立于原四项性能范围；未因后来公共预热支持短实验而扩大测量范围。结果位于
`assets/objects/eraser/000000/physics_test/summary.json` 和各后端目录。无几何或物理参数
变化时无需重建 USD。现有第一章 acceptance 经输入哈希核对后补生成 preview/summary.json，
只表示有效历史几何结果的摘要，不表示本轮重新几何验收。

端立冷启动约有 2.2 mm 水平沉降，控制漂移观察时段从 0.5 s 起；不支持初始端立位置
保持在 0.5 mm 内。0.2 mm 纸套接触可能混合纸/胶，当前不保证亚毫米接触或精确冲击。
新版 guide_release 与 stop_reset 已双后端实跑，覆盖释放连续性、多环境独立性、

GUI 脚本生命周期不适用，GUI 交互未复验；橡胶压缩、擦除、机器人和跨资产组合另行验收。

### GPU接触细步长与定量边界

三项GPU接触实验采用1 ms、四环境，保留0.5 mm漂移和2 mm几何穿透等原条件。
contact_slide正式复验最大闲置漂移0.08395072 mm、最大穿透0.54914497 mm；
free_tip和drop_orientations最大穿透0.681024/0.533815 mm，均已通过正式功能和完整媒体。
CPU及free_impulse、guide_release、stop_reset、unload_reload仍4 ms。
contact_slide仅用公开ctx.grip(..., gain_reference_dt=.004)固定增益；三向平移关闭，
角刚度2.433224037 N·m/rad、角阻尼0.006488597432 N·m·s/rad与原4 ms相同。
报告分别记录physics_dt_s=.001与gain_reference_dt_s=.004，未复制或覆盖公共控制。
CPU4 ms与GPU接触1 ms不是同条件性能，正式三轮benchmark按实际条件披露。
GPU微小支持力矩为驱动律估算，可能因读数分辨率为零；零不表示无支持反力，
不能用外加10 µN·m倒填。该定量能力尚未验证，运动/释放连续性证据独立有效。
