# 白色插头／转换头

![四分之三视图：左视觉，右碰撞](three_quarter.jpg)

白色圆角方壳，三片固定扁插脚；面向针脚看，上方一片竖直，下方两片分别倾斜为“\ /”；不可见背面为素面。

主体55 × 55 × 30 mm，插脚外露18 mm，总高48 mm。 尺寸为工程估计。一个完整刚体，视觉与碰撞随整体移动；无关节。

第二章将该模型作为完整刚体模拟，给定工程估计质量65 g；壳面静/动摩擦系数为0.55/0.42，固定金属针脚为0.32/0.24。实验覆盖壳面、针脚端和侧面低高度落放，以及顶部受力后的倾倒与撤力。针脚不会弯曲或独立运动；不模拟插座配合、拔插力或电气功能。参数未经实物测量。
