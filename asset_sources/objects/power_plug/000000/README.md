# 白色插头／转换头

![四分之三视图：左视觉，右碰撞](three_quarter.jpg)

白色圆角方壳，三片固定扁插脚；面向针脚看，上方一片竖直，下方两片分别倾斜为“\ /”；不可见背面为素面。

主体55 × 55 × 30 mm，插脚外露18 mm，总高48 mm。 尺寸为工程估计。一个完整刚体，视觉与碰撞随整体移动；无关节。

第二章将该模型作为完整刚体模拟，给定工程估计质量65 g；壳面静/动摩擦系数为0.55/0.42，固定金属针脚为0.32/0.24。实验覆盖壳面、针脚端和侧面低高度落放，以及顶部受力后的倾倒与撤力。针脚不会弯曲或独立运动；不模拟插座配合、拔插力或电气功能。参数未经实物测量。

```text
power_plug
  body [rigid]
    left_pin
    right_pin
    shell
    top_pin
```


## 物理实测

加载入口为构建目录的 object.usdz，无行为脚本。工程质量65 g、材料与几何保持不变。以下为未经实物标定的仿真值。两项实验使用2 ms步长，受力关键帧保持原0.404–0.658 s时序；不属于4 ms标准条件。CPU为TGS、16/4迭代、CCD开启；GPU为TGS、场景最小64/16迭代、CCD关闭。CPU1环境、GPU4环境；落放每环境3实例，受力每环境1实例。

| 物理量 | CPU | GPU | 来源测试与测量方式 |
| --- | --- | --- | --- |
| 三姿态最大几何穿透（mm） | 0.753 | 0.2703 | drop_orientations；全环境碰撞顶点相对地面最低值 |
| 受力最大几何穿透（mm） | 1.303 | 1.272 | tip_and_release；全环境最坏值，要求<1.5 mm |
| 全环境最小峰值倾角（deg） | 144.4 | 137.9 | tip_and_release；本体Z轴对世界Z轴的峰值夹角，要求>20° |
| 环境0最终水平位移（mm） | 653.0 | 628.1 | tip_and_release；最终与初始本体原点X坐标差 |

每个环境独立检查末0.5 s：线速度<15 mm/s、角速度<0.08 rad/s、位置跨度范数<2 mm。落放也要求最大几何穿透<1.5 mm。接触反力未采样。GPU副本接触后可分化：落放终态最大位置差0.00101 mm，受力实验33.57 mm；各副本仍独立通过相同阈值，不代表轨迹一致。CPU/GPU受力后的滑移距离和倾倒峰值存在差异，未通过修改参数将其对齐。

软件为Isaac Sim 5.1.0.0、Python 3.11.16、Torch 2.7.0+cu128；Isaac Lab源码2.3.2（扩展发行元数据0.54.3）。本机来源尚未证明与uv.lock的2.3.2.post1 wheel严格等价。实际指标见构建目录 physics_test/summary.json，详细条件和各环境结果见两后端的 result.json。
