## 物理能力与实验

`physics.py` 为单刚体配置250 g工程估计质量：页块表观密度800 kg/m³、封面1100 kg/m³约236 g，附加束带和胶层余量后取整。未实测克重/页数，质心与惯量由碰撞几何均匀分布推算。

静/动摩擦候选为封面与书脊0.55/0.40、页块0.45/0.30、固定织物0.65/0.50，恢复系数0，平均组合；碰撞contact offset 0.05 mm、rest offset 0，CCD与speculative CCD开启，16/4求解迭代，线/角阻尼0。均未经实物标定。

生成后的无行为加载入口为`object.usdz`，保留同目录构建快照。`physics_test.py`覆盖正反/短边朝下推移撤力、50 mm落放、自由侧立倾倒、同款偏置堆叠及无重力质心/偏心冲量。推移侧立对照使用仅锁转动的原生D6夹具；堆叠下层固定仅用于隔离层间滑动。其他实验无夹具，不在运动中写入资产位姿。

其余实验步长4 ms；薄束带三层堆叠在4 ms下出现超出10 mm/s接受阈值的瞬时速度波动，堆叠采用单列的2 ms例外，不能作为4 ms基准结果。平放时束带、侧立时封面边缘可能主导接触，朝向对照不是纯封面/页边摩擦系数测量。封面、页块和附件始终固定，不支持翻页、开合、束带变形、跨ID堆叠或整叠搬运验收。诊断运行完成不等于正式验收，视频/曲线及两类RTF需分别审查。

数值边界：代表小本50 mm落放在4/1 ms的瞬时穿地约1.01/1.36 mm，但2 ms为2.25 mm，超出2 mm实验阈值；峰值对离散接触步相位敏感。此结果不能外推其他步长、落高或真实冲击精度。
