## 场景设置与复现

```python
from pxr import PhysxSchema, UsdPhysics

scene = next(p for p in stage.Traverse() if p.IsA(UsdPhysics.Scene))
PhysxSchema.PhysxSceneAPI.Apply(scene).CreateEnableExternalForcesEveryIterationAttr(True)
```
