# scene-000000：桌前 X1Pro、三抽屉盒与笔

X1Pro 站在桌子 −Y 边前，面向 +Y；桌面上放 [三抽屉盒 cabinet/000000](../../objects/cabinet/000000/)（抽屉朝向机器人拉出）和 [笔 pen/000002](../../objects/pen/000002/)（笔轴沿世界 X）。两件物体原样引用 `assets/` 中的构建产物，不缩放、不改物理参数。

`scene.py` 是场景源码：桌子尺寸、机器人位姿与初始关节、两个物体的区域中心与朝向，以及按 seed 生成初始摆放的 `placement()` 和布局约束检查 `check()`。

## 布局

世界系原点在桌面中心正下方的地面，+Z 向上，单位 m。

| 对象 | 位置 | 说明 |
| --- | --- | --- |
| 桌子 | 中心 (0, 0)，1.36 × 1.02，高 0.755 | 桌板厚 0.03，四条 0.05 方腿；静摩擦/动摩擦 0.5/0.4 |
| X1Pro | base_link (−0.03, −0.80, 0)，偏航 90° | 升降 0.40 m；头俯仰 0.30 rad；双臂初始 joint2 = 0.4、joint3 = −1.0，其余关节 0 |
| 抽屉盒 | 区域中心 (0.30, 0.06)，底面贴桌面 | 偏航 0，抽屉沿 −Y 拉出 |
| 笔 | 区域中心 (−0.04, −0.36)，轴线高 0.765 | 偏航 0，笔帽朝 −X |

机器人躯干下沿（0.705 m）低于桌面，桌子前沿离 base_link 原点 0.29 m，躯干前表面与桌边留约 4 cm。

## 随机初始摆放

`placement(seed)` 用 `numpy.random.default_rng(seed)` 依次为抽屉盒、笔各抽一个 XY 偏移，各轴在 ±0.05 m 内均匀分布；只平移，朝向固定。也可用 `placement(offsets={'cabinet': (dx, dy), 'pen': (dx, dy)})` 指定偏移。

`check()` 检查三条约束：两件物体整体在桌面内；笔不进入抽屉盒及其抽屉完全拉出（0.173 m）后扫过的范围；两件物体离机器人一侧桌边至少 0.05 m。两个区域的 3 × 3（中心、边中点、角）共 81 种组合全部满足约束，见 `tests/scenes/test_scene_000000.py`。

## 区域选址依据

右臂在升降 0.40 m 时的可达范围决定了区域位置：

- 最下层抽屉放笔时手在 0.86–0.89 m 高，竖直向下的夹爪只能到 base_link 前方约 0.6 m 以内；手向抽屉里侧倾斜 40° 后可达。
- 把手抓取要求盒子离肩足够远，否则手臂折叠到上臂与前臂相碰。
- 笔区在可达范围内尽量靠右，并与抽屉拉出的区域错开。

抽屉开度用 0.12 m：露出的抽屉内腔约 0.11 m 深，179 mm 长、20 mm 粗的笔沿 X 横放，松手时手指离盒体前面板仍有余量。
